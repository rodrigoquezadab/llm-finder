# Política de datos

LLM Atlas es un agregador. Un benchmark no representa por sí solo la “inteligencia” de un modelo.

Cada puntuación debe conservar su procedencia y metodología.

## Etiquetas

- `verified`: comprobado contra fuente primaria.
- `reported`: declarado por proveedor/leaderboard.
- `estimated`: estimación; no debe usarse para rankings oficiales.

## Regla de presentación

Si faltan datos, mostrar “—”, nunca inventar una puntuación.

Los datos de demostración de la V1 deben reemplazarse por datos verificados antes de publicar un ranking como definitivo.
