# Seguridad

- Nunca colocar API keys en frontend.
- Validar URLs externas.
- Escapar contenido antes de insertarlo en HTML.
- No ejecutar HTML proveniente de proveedores.
- Usar `rel="noopener noreferrer"` para enlaces externos.
- Mantener dependencias al mínimo.
- Aplicar Content Security Policy cuando se publique.
- Backend con secretos en variables de entorno.
- Rate limiting para endpoints públicos.
- Sanitizar y validar todos los datos importados.
